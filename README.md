This is a server-side only Fabric mod that allows you to transfer your pets in Minecraft! With the simple `/pettransfer` command, you can transfer your pets to any other player online!
This mod is a hobby project of mine, so it may not be the best. If there are any bugs or issues, feel free to report them on [GitHub Issues](https://github.com/PRR628CRAFT/pet-transfer/issues)!

# 💖 Tutorial

The `/pettransfer` command can be used by any player, regardless of permission. This is a table of what each subcommand does.
| Subcommand | Description                                                                                                                |
|------------|----------------------------------------------------------------------------------------------------------------------------|
| `help`     | Displays the help menu, listing the function of all subcommands.                                                           |
| `transfer` | Initiates the transfer of a pet entity you are looking directly at.                                                        |
| `confirm`  | Once `transfer` is run, this subcommand is run to complete your side of the transfer.                                      |
| `accept`   | Once `confirm` is run, the recipient is notified and can use this subcommand to accept the pet, and complete the transfer. |
| `credits`  | Shows all credits of the mod, including developers, designers, and translators.                                            |
| `version`  | Prints the version of the mod.                                                                                             |

# ❓ FAQ

<details>
<summary>Is the mod needed on the client?</summary>
  No, that is the cool part! It is a fully server-side mod, it does absolutely nothing on the client, so do not even install it xD
</details>

<details>
<summary>Will the mod be backported?</summary>
  No, I do not plan to backport to versions before 26.1 due to the obfuscation. Currently only 26.2+ is supported.
</details>

<details>
<summary>Will there be a NeoForge/Paper version?</summary>
  I currently do not plan on making a version for NeoForge or Paper, as that would require a rewrite of the mod. However, the mod is pretty small, so it is something I consider. If you would like to help port it, DM me on Discord for permission.
</details>
